## 🛠️ Como Acessar o Sistema

Para rodar este projeto em sua máquina local, siga as instruções abaixo:

1. **Pré-requisitos**:
   - Certifique-se de ter um servidor web local (como Apache) com suporte a PHP instalado.
   - Tenha um SGBD MySQL ou MariaDB instalado e em execução.

2. **Configuração do Banco de Dados**:
   - Importe o script de criação das tabelas (fornecido na pasta `/database`) no seu SGBD MySQL/MariaDB.
   - Configure as credenciais de acesso ao banco de dados no arquivo de conexão PHP do projeto (verifique as instruções no arquivo `instrucoes.txt`).

3. **Execução**:
   - Clone este repositório para o diretório raiz do seu servidor web (ex: `htdocs` ou `www`).
   - Acesse o sistema através do seu navegador utilizando o endereço local configurado (ex: `http://localhost/projeto-whac-a-mole`).
   - Na página inicial, realize o cadastro ou login para começar a jogar.
